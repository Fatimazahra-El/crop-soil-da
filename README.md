# Crop, Soil, and Fertilizer Data Analysis
This project explores agricultural data to uncover patterns between soil types, crop performance, moisture levels, and fertilizer usage. The goal is to support data-driven farming decisions through descriptive analysis and real-world interpretation.

📌 Objectives
Analyze relationships between soil type, crop type, and nutrient levels

Detect nutrient deficiencies (Nitrogen, Phosphorus, Potassium)

Provide actionable insights for farmers and agronomists

🧰 Tools Used
Excel: for data cleaning, statistical analysis, and visualization

Data visualization: Histograms, box plots, and heatmaps

Domain knowledge: Agriculture, crop science, and soil fertility

📊 Key Insights
Moisture and temperature levels are stable across most soil types, suggesting uniform irrigation or climate.

Nitrogen and phosphorus levels vary significantly and require targeted fertilizer strategies.

Fertilizer distribution reflects both soil needs and crop-specific nutrient demands.

Balanced fertilizers like 17-17-17 offer broader nutrient coverage, especially in low-nutrient soils.

🌍 Real-World Impact
This project can help farmers:

Choose the right fertilizer–crop–soil combinations

Avoid nutrient waste and improve sustainability

Apply precision agriculture practices using simple tools like Excel
